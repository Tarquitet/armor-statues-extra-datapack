# ⚔️ StatuesExtra

![Vanilla Tweaks Addon](https://img.shields.io/badge/Addon-Vanilla_Tweaks-orange?style=for-the-badge)

A datapack that adds advanced customization mechanics to **Vanilla Tweaks Armor Stands**, directly inspired by [Roundaround's ArmorStands mod](https://modrinth.com/mod/armor-stands). It brings mod-like features to a 100% vanilla environment.

## ✨ Features

- **🛡️ Invulnerability & Slot Lock:** Makes the armor stand immune to all damage and prevents players from stealing or swapping its equipment.
- **⚔️ Mace Shield:** Spawns an invisible villager that absorbs Mace smash attacks. This prevents the armor stand's pose from breaking and successfully triggers the **Wind Burst** enchantment effect.
- **⚖️ Dynamic Scale:** Instantly adjust the armor stand's size (0.5x to 3.0x) with built-in safety locks to prevent conflicts.

## 🛠️ Installation

1. Download the latest release `.zip` file.
2. Place it in your world's `datapacks/` folder.
3. Run `/reload` in-game.
4. *Note: This datapack is designed to work alongside the [Vanilla Tweaks Armor Statues datapack](https://vanillatweaks.net/) for pose editing.*

## 📚 How to Use

1. Craft a **Book and Quill**.
2. Sign it with the exact title: `StatuesExtra` (case-sensitive, no spaces).
3. The book will automatically transform into the interactive StatuesExtra book.
4. Hold the book, look at an armor stand (within 3 blocks), and click the buttons in the book to apply changes.

> [!WARNING]
> **CRITICAL WARNINGS**
> - **Before editing poses:** You **MUST** turn OFF Invulnerability and Mace Shield before using the original Vanilla Tweaks book to edit poses, or the pose might break permanently.
> - **Scaling restriction:** The system will automatically block size changes if the Mace Shield is active. Turn the shield OFF, adjust the scale, and turn it back ON if needed.

## 🗑️ Clean Uninstallation

To prevent invisible villagers from remaining in your world, please uninstall properly:
1. Run this command: `/function as_extra:uninstall` *(or click the command on Page 3 of the book)*.
2. Delete the datapack folder.
3. Run `/reload`.

## ✨ Características

- **🛡️ Invulnerabilidad y Bloqueo:** Hace que el armor stand sea inmune a todo daño y evita que los jugadores roben o intercambien su equipamiento.
- **⚔️ Mace Shield (Escudo de Mazo):** Genera un aldeano invisible que absorbe los golpes del mazo. Esto evita que la pose del armor stand se rompa y permite activar correctamente el efecto **Wind Burst**.
- **⚖️ Escala Dinámica:** Ajusta el tamaño del armor stand al instante (0.5x a 3.0x) con bloqueos de seguridad integrados.

## ️ Instalación

1. Descarga el archivo `.zip` de la última versión.
2. Colócalo en la carpeta `datapacks/` de tu mundo.
3. Ejecuta `/reload` en el juego.
4. *Nota: Este datapack está diseñado para funcionar junto al [datapack Armor Statues de Vanilla Tweaks](https://vanillatweaks.net/) para editar poses.*

## 📚 Cómo Usar

1. Crea un **Libro y Pluma**.
2. Fírmalo con el título exacto: `StatuesExtra` (respeta las mayúsculas, sin espacios).
3. El libro se transformará automáticamente en el libro interactivo de StatuesExtra.
4. Sostén el libro, mira a un armor stand (a menos de 3 bloques) y haz clic en los botones del libro para aplicar los cambios.

> [!WARNING]
> **ADVERTENCIAS CRÍTICAS**
> - **Antes de editar poses:** **DEBES** desactivar la Invulnerabilidad y el Mace Shield antes de usar el libro original de Vanilla Tweaks para editar poses, o la pose podría romperse permanentemente.
> - **Restricción de escala:** El sistema bloqueará automáticamente los cambios de tamaño si el Mace Shield está activo. Apaga el escudo, ajusta la escala y vuelve a activarlo si es necesario.

## 🗑️ Desinstalación Limpia

Para evitar que queden aldeanos invisibles en tu mundo, desinstálalo correctamente:
1. Ejecuta este comando: `/function as_extra:uninstall` *(o haz clic en el comando en la Página 3 del libro)*.
2. Elimina la carpeta del datapack.
3. Ejecuta `/reload`.
