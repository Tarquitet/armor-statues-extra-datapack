# ⚔️ StatuesExtra

A datapack that adds advanced customization mechanics to **Vanilla Tweaks Armor Stands**, directly inspired by [Roundaround's ArmorStands mod](https://modrinth.com/mod/armor-stands). It brings some mod-like features to a 100% vanilla environment.

## ✨ Features
- **🛡️ Invulnerability & Slot Lock:** Makes the armor stand immune to all damage and prevents players from stealing or swapping its equipment.
- **⚔️ Mace Shield:** Spawns an invisible entity that absorbs Mace smash attacks. This prevents the armor stand's pose from breaking and successfully triggers the **Wind Burst** enchantment effect.
- **⚖️ Dynamic Scale:** Instantly adjust the armor stand's size (0.5x to 3.0x) with built-in safety locks to prevent conflicts.

## 🎮 Use Cases
- **Minigames:** Perfect for recreating mechanics like **Xisumavoid's MaceRace**, where players need to bounce off armor stands without breaking them.
- **Decoration:** Create monumental statues, detailed miniatures, or secure museum exhibits without worrying about griefing.
- **Adventure Maps:** Design custom NPCs or bosses with specific sizes and protected gear.

## 📚 How to Use
1. Craft a **Book and Quill**.
2. Sign it with the exact title: `StatuesExtra` (case-sensitive).
3. The book will automatically transform into the interactive StatuesExtra book.
4. Hold the book, put in a lectern in front at an armor stand (within 3 blocks, recommended 1 block), and click the buttons in the book to apply changes.

> ⚠️ **CRITICAL WARNINGS**
> - **Before editing poses:** You **MUST** turn OFF Invulnerability and Mace Shield before using the original Vanilla Tweaks book to edit poses, or the pose might break permanently.
> - **Scaling restriction:** The system will automatically block size changes if the Mace Shield is active. Turn the shield OFF, adjust the scale, and turn it back ON if needed.

## 🗑️ Clean Uninstallation
To prevent invisible villagers from remaining in your world, please uninstall properly:
1. Run this command: `/function as_extra:uninstall`.
2. Delete the datapack folder.
3. Run `/reload`.

# ⚔️ StatuesExtra

Un datapack que añade mecánicas de personalización avanzadas a los **Armor Stands de Vanilla Tweaks**, inspirado directamente en el [mod ArmorStands de Roundaround](https://modrinth.com/mod/armor-stands). Trae algunas funciones de mod a un entorno 100% vanilla.

## ✨ Características
- **🛡️ Invulnerabilidad y Bloqueo:** Hace que el armor stand sea inmune a todo daño y evita que los jugadores roben o intercambien su equipamiento.
- **⚔️ Mace Shield (Escudo de Mazo):** Genera una entidad invisible que absorbe los golpes del mazo. Esto evita que la pose del armor stand se rompa y permite activar correctamente el efecto **Wind Burst**.
- **⚖️ Escala Dinámica:** Ajusta el tamaño del armor stand al instante (0.5x a 3.0x) con bloqueos de seguridad integrados.

## 🎮 Casos de Uso
- **Minijuegos:** Perfecto para recrear mecánicas como el **MaceRace de Xisumavoid**, donde los jugadores deben rebotar en armor stands sin romperlos.
- **Decoración:** Crea estatuas monumentales, miniaturas detalladas o exhibiciones de museos seguras contra el griefing.
- **Mapas de Aventura:** Diseña NPCs o jefes personalizados con tamaños específicos y equipamiento protegido.

## 📚 Cómo Usar
1. Crea un **Libro y Pluma**.
2. Fírmalo con el título exacto: `StatuesExtra` (respeta las mayúsculas).
3. El libro se transformará automáticamente en el libro interactivo de StatuesExtra.
4. Sostén el libro, colócalo en un atril en frente del armorstand (a menos de 3 bloques, se recomienda 1 bloque) y haz clic en los botones del libro para aplicar los cambios.

> ⚠️ **ADVERTENCIAS CRÍTICAS**
> - **Antes de editar poses:** **DEBES** desactivar la Invulnerabilidad y el Mace Shield antes de usar el libro original de Vanilla Tweaks para editar poses, o la pose podría romperse permanentemente.
> - **Restricción de escala:** El sistema bloqueará automáticamente los cambios de tamaño si el Mace Shield está activo. Apaga el escudo, ajusta la escala y vuelve a activarlo si es necesario.

## 🗑️ Desinstalación Limpia
Para evitar que queden aldeanos invisibles en tu mundo, desinstálalo correctamente:
1. Ejecuta este comando: `/function as_extra:uninstall`.
2. Elimina la carpeta del datapack.
3. Ejecuta `/reload`.
